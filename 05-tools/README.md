# Этап 5 — Tools (Function Calling)

## Цели

- Дать LLM возможность вызывать наш код как «инструменты»
- Описать инструмент через `@Tool` + `@P`
- Понять цикл: LLM → запрос инструмента → выполнение → ответ → LLM
- Обрабатывать ошибки и таймауты инструмента

## Ключевые концепции

| Концепция | Назначение |
|-----------|-----------|
| `@Tool` | помечает метод как инструмент |
| `@P` | описание параметра для модели |
| `ToolSpecification` | схема инструмента, которую видит LLM |
| `ToolExecutor` | кастомное исполнение/перехват |
| Tool-loop | агент вызывает инструменты в цикле, пока не выдаст финальный ответ |

## Что строим

1. **Калькулятор**: `add`, `subtract`, `multiply`, `divide`
2. **Погода**: REST-вызов внешнего API
3. **БД**: поиск пользователей через Spring Data
4. **Файлы**: чтение/запись с белым списком директорий
5. Логирующий `ToolExecutor` — видеть в консоли каждый вызов
