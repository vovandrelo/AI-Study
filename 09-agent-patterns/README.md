# Этап 9 — Агентные паттерны (одиночный агент)

## Цели

- Реализовать три классических паттерна агентского рассуждения вручную
- Понять, какой паттерн в каком сценарии работает лучше
- Подготовить почву для LangGraph4j (этап 10) — там же паттерны, но как граф

## Паттерны

### 1. ReAct (Reason + Act)
Цикл: **Thought → Action → Observation → Thought → … → Answer**.
Хорош для простых задач с инструментами. По сути — `AiServices` с `@Tool` уже это делает за тебя; здесь покажем «под капотом» вручную.

### 2. Plan-and-Execute
Сначала отдельный LLM-вызов строит **план** из шагов, потом другой агент выполняет шаги по очереди. Хорош для длинных задач, где нужен общий вид с самого начала.

### 3. Reflection / Self-Critique
Агент пишет ответ → второй проход критикует → третий переписывает. N итераций. Хорош для качества: код-ревью, тексты, длинные обоснования.

## Что строим

Один тест-кейс на всех: «спланируй и реализуй REST-endpoint по описанию» — прогоним через ReAct, Plan-and-Execute и Reflection, сравним результат и количество вызовов LLM.
